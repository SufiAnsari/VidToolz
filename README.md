# VidToolz 🎥🎙️

VidToolz is a modern, high-performance video & audio processing suite built with Next.js, React, Tailwind CSS, and client-side ONNX Whisper AI model execution.

## Features

- 🎙️ **AudioScribe**: AI-powered audio transcription with speaker diarization and real-time streaming displays.
- 📝 **Transcriptr**: Dedicated video transcription tool with subtitle export (SRT, VTT, JSON, TXT).
- 🤖 **On-Device Whisper AI**: Client-side ML inference using Xenova's quantized Whisper-tiny model.
- ⚡ **Next.js App Router**: High performance, React Server Components, and sleek API endpoints.
- 🎨 **Modern Design**: Designed with glassmorphism, responsive Tailwind styling, and audio waveform visualizations.

## Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Styling**: Tailwind CSS, Lucide Icons, Custom Animations
- **ML / AI**: ONNX Runtime Web / `@xenova/transformers` (Whisper-tiny model)
- **Language**: TypeScript

## Getting Started

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
